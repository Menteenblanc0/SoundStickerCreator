# Seguridad

Reporta fallos de validación, exposición de secretos y errores de dependencias al responsable del repositorio que distribuya esta copia. Redacta rutas, teléfonos, números de dispositivo, claves, QR y mensajes. Incluye versión y un caso de prueba sintético cuando sea posible.

El proyecto fija dependencias npm con lockfile, instala con lifecycle scripts desactivados y valida los hashes de los runtimes y ruedas para Windows. El build distribuye Node y Python. FFmpeg se instala y actualiza por separado. La recepción de medios es opcional y tiene límites de tamaño y tiempo. Revisa [Privacidad](docs/PRIVACY.md) para el ciclo de vida de la sesión.
