# Avisos de terceros

MIT cubre el código propio de este proyecto. Las dependencias conservan sus licencias.

| Componente distribuido | Avisos incluidos |
| --- | --- |
| CPython 3.12.16, Tcl/Tk y bibliotecas de python-build-standalone | Licencia de PSF y términos de bibliotecas en el runtime de Astral. |
| Pillow 13.0.0 | HPND y avisos de códecs vendorizados en sus metadatos de rueda. |
| TkinterDnD2 0.7.0 y TkDND | Texto de licencia incluido en la rueda. |
| Node.js 24.22.3 | Licencia MIT y avisos de componentes en `tools/NODE-LICENSE`. |
| Biblioteca estándar de Go 1.27.4 | Licencia BSD en `tools/GO-LICENSE`. |
| Baileys 7.0.0-rc14 y dependencias npm | Licencias preservadas dentro de `transport/node_modules`. |
| NSIS 3.11 | El instalador incorpora el stub y complementos redistribuibles de NSIS bajo sus respectivos términos. |

FFmpeg, FFprobe y FFplay se instalan por separado. No forman parte del instalador ni del portable. Una distribución que incorpore esos binarios debe revisar la configuración y las licencias de su compilación.
