# Historial

## 0.1.0 · 2026-11-24

- Analizador WebP/RIFF con EXIF de ambos órdenes de bytes y duración de fotogramas.
- Motor multimedia local FFmpeg, editor Tk, generación, previsualización y exportación.
- CLI de envío y diagnóstico con una extensión Protobuf experimental de Baileys.
- Distribución portable e instalador de Windows x64 con runtimes de Python y Node.
